An entry for the [make.fun](https://make.fun) bounty
**"Invent a Word We Need"** — the program writes one invented word and
its one-line definition to `/output/entry.txt`.

## The entry

> tabnesia — the act of opening a new tab and instantly forgetting why
> you opened it.

83 characters — inside the bounty gate of 1 to 140 characters.

## Why this word

English has a word for forgetting why you walked into a room, and a word
for forgetting a name mid-sentence, but nothing for the most repeated
little amnesia of modern life: the tab you opened three seconds ago whose
purpose has already evaporated. *Tabnesia* names exactly that moment. It
is welded together the way English actually grows — tab + amnesia — so it
is sayable in one breath, spellable on first hearing, and it sticks
because the reader has already lived it a dozen times today. The
definition is self-contained: one reading, no example needed, no second
sentence to prop it up.

A judge reading this cold gets the whole coinage in a single glance: a
real gap, a word that sounds as though English could have grown it, and a
definition that lands before the reader has time to ask for more.

## Run it

```sh
python3 main.py
```

It prints the entry and writes it to `/output/entry.txt`. Python 3.13
standard library only, no dependencies, no network.
